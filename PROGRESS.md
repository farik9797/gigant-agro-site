## Сделано (2026-09-18): все страницы свёрстаны
Сайт переведён на сборку из общих частей, чтобы шапка/подвал/стили не расходились между страницами.

**Как устроено**
- `partials/head.html` — meta, шрифты, конфиг Tailwind, стили. Плейсхолдеры `{{TITLE}}`, `{{DESC}}`, `{{OGTITLE}}`, `{{OGIMAGE}}`.
- `partials/header.html` — прелоадер, skip-link, плавающая навигация, мобильное меню.
- `partials/footer.html` — подвал, плавающий WhatsApp, мобильная панель, общий JS (все обработчики защищены проверками на null, поэтому один скрипт работает на всех страницах).
- `pages/*.html` — только содержимое `<main>` каждой страницы.
- `build.py` — собирает корневые `.html` из partials + pages. Для внутренних страниц добавляет `page-inner` к `<body>` (белая шапка вместо тёмного стекла) и переписывает якоря главной в `index.html#...`.
- `make_pages.py` — генерирует тела страниц из данных проекта (цены, характеристики, контакты) и общих блоков: хлебные крошки со schema.org, шапка страницы, карточка товара, карточка комплекта, CTA-полоса.

**Команды**
```
python3 make_pages.py      # перегенерировать тела страниц
python3 build.py           # собрать все страницы
python3 build.py catalog   # собрать одну
```

**Страницы (22)**
Главная · Каталог · 8 категорий · Карточка товара GIGANT 15 · Подбор комплекта · Как выбрать · Инструкции и схемы · Доставка и оплата · Гарантия и возврат · О компании · Контакты · FAQ · Спасибо за заявку · Политика конфиденциальности · 404. Плюс `sitemap.xml` и `robots.txt`.

## Сделано (2026-09-21): оптимизация и UX-аудит
Запрос: «анализируй сайт и оптимизируй и улучши UI UX frontend design».

**Скорость (Lighthouse mobile, главная)**
До (Pages, Play CDN): Performance 63, FCP 4,7 с, LCP 5,9 с, TBT 120 мс, вес 1650 KB.
После (Pages, коммит e7187ac): Performance 99, FCP 1,2 с, LCP 1,5 с, TBT 0 мс, CLS 0,015, вес 493 KB. A11y / Best Practices / SEO = 100. Отчёты: `.audit/` (не в git).

**Что изменено**
- Убраны все CDN: Tailwind Play CDN → статическая сборка Tailwind CLI (`assets/css/site.css`, ~46 KB min); Lucide runtime → SVG встраиваются при сборке из `lucide-static`; Google Fonts → свои woff2 (`assets/fonts/`, вариативный Golos Text + Vollkorn Italic, preload кириллицы и латиницы).
- JS вынесен в `assets/js/site.js` (defer, хэш в `?v=`), CSS тоже с хэшем — кэш Pages больше не мешает.
- Картинки: `optimize_images.py` → WebP 480/640/800/1200 (герои до 1920) в `assets/img/opt/` + `manifest.json`; `build.py` подставляет `srcset`/`sizes`, реальные width/height, preload героя; первая картинка внутренних страниц грузится сразу (fetchpriority).
- Форма заявки: раньше показывала «Заявка принята», ничего не отправляя. Теперь собирает сообщение и открывает WhatsApp менеджера (`wa.me/77054285707`). Бэкенда нет — это единственный надёжный канал на статике.
- Кнопки «Заказать» ведут в форму с подставленным товаром: на главной `data-tovar`, на внутренних `kontakty.html?tovar=…#leadForm`; результат подбора тоже передаёт товар.
- Навигация: `aria-current` + видимая подсветка текущего раздела в шапке, мобильном меню и нижней панели; нижняя панель на внутренних страницах ведёт на `catalog.html` и `podbor.html`.
- Прелоадер: прячется после разбора страницы и первой картинки (мин. 500 мс, страховка 2,5 с), а не после полной загрузки всех изображений.
- «Почему GIGANT Agro»: список преимуществ 2 колонки вместо тесных 3.
- SEO: canonical, og:url, абсолютный og:image, Product JSON-LD на карточке GIGANT 15.
- A11y: skip-link на внутренних страницах ведёт к содержимому, боковые колонки больше не `<aside>` внутри `<main>`; axe (WCAG 2.2 AA + best-practice) — 0 нарушений на главной, категории, контактах.

## Ключевые решения (и почему)
- v2: шрифт один — Golos Text (900 для заголовков, 400 текст) + Vollkorn Italic для одного акцентного слова; серифы из reflex-reject-списка impeccable (Playfair, Cormorant) не взяты. Фон #F4F6F1 с оттенком бренда вместо «кремового» дефолта.
- Стекло — только навигация и одна карточка в hero (по премиум-скиллу), остальное — плоские карточки с рамкой 1 px.
- Отзывов нет → вместо блока testimonials реальный рейтинг Ozon в hero и в доставке.
- Палитра: зелёный бренда из логотипа как цвет доверия, сигнальный жёлтый #FFC400 как единственный цвет действия (табличка «Осторожно, электроизгородь» лежит в комплекте GIGANT, и на Satu кнопки уже жёлтые — клиенты к нему привыкли). Зелёный #5A984B не проходит контраст для мелкого текста → для кнопок с белым текстом взят #3E7A34.
- Шрифты Geologica + Golos Text: кириллические, технический характер, не «дефолтные AI».
- Подбор комплекта — главный дифференциатор, поэтому стоит сразу под hero и в мобильной панели действий.
- Верхняя зелёная полоса шапки сохранена как узнаваемость со старого сайта.
- Блок отзывов не публиковать пустым (на Satu 0 отзывов).
